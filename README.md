# 🚀 Conexão do Futuro - Global Solution

## 📄 Resumo do Projeto

**Tema:** O Futuro do Trabalho – Conectando pessoas, competências e propósito por meio da tecnologia.

Este projeto, desenvolvido para a Global Solution (disciplinas de Front-End Design e Web Development), é uma aplicação web interativa que simula uma plataforma profissional.

A aplicação consiste em uma Landing Page que apresenta uma listagem de perfis profissionais (dados carregados de um Array em JavaScript) e permite a visualização de informações detalhadas em um modal. O projeto também inclui um quiz funcional sobre o mercado de trabalho.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização (incluindo Flexbox para layout), animações (`@keyframes`) e transições.
* **JavaScript (ES6+):** Manipulação do DOM, renderização dinâmica de perfis (Array de 10 objetos), funcionalidade do Quiz e interatividade do modal.
